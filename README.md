# EV Calculus Lab — 미적분으로 찾는 전기차 최적 운행

가상의 전기차를 직접 운전하고, 같은 출발·도착 지점의 후보 경로에서 계산한 에너지 최소 운행과 비교하는 한국어 학습용 시뮬레이터입니다.

## 가장 쉬운 실행: HTML 파일 열기

저장소의 **EV-Calculus-Lab-v3-Learning.html** (또는 EV-Calculus-Lab.html)을 다운로드한 후 더블클릭하여 Chrome 또는 Edge에서 여세요. Python 설치, 터미널, `127.0.0.1:8000`, 인터넷 연결이 필요 없습니다. GitHub 파일 화면에서는 Raw/다운로드 버튼으로 파일을 저장하세요. GitHub의 소스 코드 미리보기는 앱 실행 화면이 아닙니다.

계산은 브라우저 안에서 수행됩니다. `static/index.html`도 함께 있는 engine.js, app.js, style.css를 이용해 직접 열 수 있습니다. 단일 파일을 다시 생성하려면 `python scripts/build_offline.py`를 실행하세요.

기존 Python 서버는 `python app.py`로 계속 실행할 수 있습니다.

## 시작 화면: 미적분 사전 학습

v3 파일을 열면 주행 화면보다 먼저 3단계 사전 학습이 표시됩니다. 3가지 원리를 확인하고 완료 버튼을 누르면 6단계 운행 실험으로 이동합니다.

1. 속도 접선 dv/dt = 가속도, 누적 에너지 접선 dE/dt = P/3600: 가속도와 관찰 시점을 조절하며 두 그래프와 접선을 비교.
2. 도로 기울기 dh/ds = sinθ와 중력 저항, 전력 그래프 아래 부호 있는 넓이: 경사만 바꾸어 에너지 변화 관찰.
3. 평지 거리당 소비량 e(v)와 도함수 e′(v): 접선 기울기의 부호와 최솟값 속도 관찰.

각 화면은 단위, 고정된 조건과 모델 한계를 설명합니다. 그래프의 기울기가 어떤 함수의 미분인지 구분하며, 가속도만으로 총 소비량을 판단하지 않도록 안내합니다. 주행 화면의 ‘사전 학습 다시 보기’로 재확인할 수 있습니다.

## 효율적인 운행을 배우는 6단계

앱 상단의 학습 과정에서 가속·감속 손실 → 속도와 시간 → 경로 선택 → 회생제동 → 시간 제약 → 직접 개선하기 순서로 실험합니다. 각 단계의 A/B 버튼은 비교할 조건을 설정하고 운행을 분석합니다. 마지막 단계는 같은 조건으로 직접 두 번 주행합니다.

결과에는 총 소비 Wh, 실제 시간, 회수 Wh, 같은 경로의 계산 기준 Wh가 함께 표시됩니다. 목표와 해석 질문을 읽고 학습 완료를 표시할 수 있습니다. 기록은 현재 열린 화면에서만 유지되며, 새로 열거나 새로고침하면 초기화됩니다.

## 두 운행을 동시에 비교

직접 주행을 끝내거나 예시 운행을 선택하면 **내 운행과 계산 기준을 동시에 보기** 화면에서 두 차량이 같은 경과 시간으로 재생됩니다.

- 보라색은 사용자 운행, 초록색은 계산 기준입니다.
- 전체 후보의 최소 에너지 경로 또는 사용자와 같은 경로의 최소 에너지 운행을 선택할 수 있습니다.
- 두 고도 단면은 같은 거리·고도 축척을 사용합니다. 차량의 위치, 속도, 누적 Wh를 함께 표시합니다.
- 동시 재생, 일시정지, 시간 슬라이더로 원하는 시점을 비교합니다. 먼저 도착한 차량은 목적지에서 대기하며 더 이상 운행 에너지를 누적하지 않습니다.
- 계산 기준은 정해진 격자 안의 최솟값이며 연속 공간의 이상적 전역 최적해는 아닙니다. 비교할 해가 없으면 안내를 표시합니다.

## 사용 순서

1. 언덕 직행·강변 우회·도심 연결 중 하나를 고르거나 나만의 경로를 설계합니다. 커스텀 경로는 총길이·두 언덕 높이·제한속도를 조절합니다.
2. 질량, 바람, 제한시간을 설정합니다. 상세 설정에서 공기저항, 구름저항, 회생 효율, 구동 효율, 보조전력을 바꿀 수 있습니다.
3. **직접 주행**을 누르고 ↑/↓ 키 또는 가속/감속 버튼으로 목표 속도를 조절합니다. 한 번 누를 때 2m/s(7.2km/h) 바뀌며, 목표는 2~20m/s입니다.
4. 출력·가감속·제한속도 및 정차 보조를 적용해 다음 25m 구간 속도를 결정합니다. 속도를 연속적으로 직접 조작하는 고정밀 운전 게임이 아니라 **구간별 목표 속도 실험**입니다. 중간에 완전히 정지해 4초 기다리고, 도착 시에도 정지합니다.
5. 완료되면 내 에너지, 후보 경로별 계산 에너지, 동일 경로의 에너지 차이, 학습 피드백이 나옵니다. 또는 세 가지 예시 운행을 즉시 분석할 수 있습니다.
6. 속도·전력·누적 에너지 그래프를 비교하고, 내 운행/계산 기준을 재생하거나 CSV를 저장합니다. 설정을 바꾸면 이전 결과는 초기화됩니다.

**비교의 공정성:** 모든 경로는 출발·도착 고도 0m, 공통 중간 지점 고도 8m, 중간 4초 정차, 출발·도착 속도 0 조건입니다. 설정된 공통 마감시간 T 이내의 운행만 평가합니다. 도착시각이 정확히 같은 운행끼리의 비교는 아닙니다. 실제 위치 기반 지도 대신 공통 체크포인트를 잇는 가상 고도 단면을 사용합니다. 제한시간을 넘긴 운행은 절감률을 표시하지 않습니다.

## 미적분과 물리

거리 s는 도로의 **호 길이**, 높이는 h입니다. 따라서 `sinθ = dh/ds`이고, 경사각은 `asin(dh/ds)`입니다.

```text
a = dv/dt = (v₁² − v₀²) / (2Δs)
Δt = 2Δs / (v₀ + v₁)
F = ma + mg sinθ + Crr mg cosθ + ½ρ Cd A (v+w)|v+w|
Pwheel = Fv
Pbattery = Pwheel/ηdrive + Paux                (Pwheel ≥ 0)
Pbattery = −min(−Pwheel, 45000)ηregen + Paux    (Pwheel < 0)
E = ∫ Pbattery dt / 3600                      [Wh]
```

`w>0`는 맞바람, `w<0`는 뒷바람입니다. 한 구간에서는 일정 가속도로 속도가 변한다고 가정하며 8개 시간 소구간의 중점법으로 전력을 수치 적분합니다. 기계적 회생 한도를 넘은 제동 에너지는 마찰 브레이크에서 소모됩니다. 정차 중에도 보조전력을 소비합니다. 전력 그래프는 각 구간의 평균 전력을 표시하므로 계단 아래 넓이가 계산된 에너지와 일치합니다. 실시간 누적 에너지 표시는 구간 평균 전력을 이용한 보간입니다.

### 평지의 효율 속도를 미분으로 찾기

평지·무풍·일정 속도·일정 구동 효율에서 거리당 에너지:

```text
e(v) = (Crr mg + ½ρ Cd A v²)/η + Paux/v
e′(v) = ρ Cd A v/η − Paux/v²
v* = (Paux η / (ρ Cd A))^(1/3)
```

기본 차량의 참고 속도는 약 33.4km/h입니다. 이 식은 가속·제동·경사·시간 제약이 있는 전체 경로의 최적 속도와 다릅니다. 보조전력이 0이면 위 모델에서 양의 유한한 최적 속도는 없고, v→0에서 에너지의 하한에 접근합니다.

### 전체 경로 최적화

거리 25m, 속도 2m/s(0~20m/s), 시간 0.5초의 격자 상태에서 동적 계획법(DP)을 실행합니다. 상태는 `(거리 노드, 속도, 누적 격자 시간)`이며, 누적 배터리 에너지를 최소화합니다. 중간·종점에서 속도 0을 강제하고 가속 2m/s², 감속 3m/s², 바퀴 구동 출력 85kW를 제한합니다. 출력 제한은 구간 양 끝 및 내부 전력 극값에서도 검사합니다.

구간별 시간을 0.5초 단위로 **올림**해 누적하므로 기준 운행의 실제 시간은 격자 시간 이하입니다. 최대 보수 오차는 구간 수 × 0.5초 미만입니다. 역방향 도달 가능성 검사로 이후 필수 정차에 도달할 수 없는 전이를 배제합니다. 음의 회생 에너지가 있어도 거리 순서의 비순환 그래프라 DP가 가능합니다.

**해의 의미:** 정해진 경로 후보·속도 격자·보수적인 시간 격자 내에서 수치 비용의 최솟값입니다. 연속 공간의 전역 최적해를 보장하지 않으며, 특히 촉박한 시간에서는 실제 가능한 운행이 있어도 격자 해가 없을 수 있습니다. 사용자의 운행이 보수적 격자 기준보다 낮은 에너지를 달성할 수 있으며, 이 경우도 그대로 표시합니다. 경로별 비교는 총 Wh가 목적함수이고 Wh/km는 참고값입니다.

## 모델 범위

교육용 가상 차량으로, 실제 차량의 주행거리 예측값으로 사용할 수 있는 실측 보정 모델이 아닙니다. 배터리 SOC·온도·충전 수용 한계·모터 효율 맵·타이어 미끄럼·곡선·교통 신호는 반영하지 않습니다. 일정 효율과 일정 환경을 가정합니다. 회생은 45kW 기계 출력 한도이며 기본 전기 변환 효율 65%를 적용합니다.

모델 구성 참고: [Brooker et al. (2015), FASTSim: A Model to Estimate Vehicle Efficiency, Cost and Performance](https://research-hub.nlr.gov/en/publications/fastsim-a-model-to-estimate-vehicle-efficiency-cost-and-performan-2/), DOI: 10.4271/2015-01-0973. 힘·전력 기반 접근과 저항·경사·회생 요소를 참고했으며 FASTSim 자체를 사용하거나 그 검증 결과를 본 프로젝트에 적용한 것은 아닙니다.
